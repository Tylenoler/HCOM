## Variant: Material Dark（深色科技感）

### Design stance
贴近 Google Material Design 的深色工程工具风格，结构清晰、专业、高信息密度，强调"一眼看清收发数据流"。

### Key choices
- 布局：三区主干 + 左右可折叠侧边栏（完全按产品说明书定稿）
- 配色：深色底（#0f1419）+ 单一蓝主色（#4c8dff）
- 字体：Inter（界头）+ JetBrains Mono（数据流/HEX）
- 交互：RX 蓝 / TX 绿方向色标；帧按块高亮；打开/关闭端口状态切换；发送后实时追加 RX
- 动效：按钮 hover、TAB 切换、端口开关状态变化

### Trade-offs
- 强项：专业、克制、信息密度高，嵌入式工程师熟悉的工具感
- 弱项：偏冷静，视觉冲击力不如高饱和/渐变风格

### Best for
追求"像个正经工程工具"、重视数据可读性和长时间使用舒适度的用户。
